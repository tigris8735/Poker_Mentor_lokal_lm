## 3. Технические детали реализации

### 3.1. Ключевые архитектурные решения

#### **Асинхронная архитектура**
```python
# Пример асинхронного обработчика
@router.message(Command("analyze"))
async def analyze_handler(message: types.Message):
    await message.answer("🤔 Анализирую раздачу...")
    analysis = await ai_service.analyze_hand(message.text)
    await message.answer(f"🎯 Анализ: {analysis}")
```

#### **Модульная структура сервисов**
```
bot/
├── services/           # Бизнес-логика
│   ├── ai_service.py   # Управление AI
│   ├── game_manager.py # Управление играми
│   └── database.py     # Работа с БД
├── handlers/           # Обработчики команд

│   └── system.py       # Системные команды
```
